WarehouseManagement_Oshchepkov

Описание проекта
WPF приложение для управления складом с партионным учетом товаров.

Функционал
- Управление организациями (CRUD + подтверждение удаления)
- Управление складами (привязка к организации)
- Управление товарами (таблица, поиск, сортировка, CRUD)
- Импорт товаров из CSV
- Партионный учет через накладные (приход/расход)
- Светлая тема оформления
- Unit-тесты для всех сервисов

Технологии
- C# / WPF / .NET 8.0
- MVVM
- NUnit (Unit-тесты)

Как запустить проект

Важно! Правильная настройка запуска

При открытии решения Visual Studio может назначить запускаемым проектом `WarehouseManagement_Oshchepkov.Data` (библиотека).

Чтобы запустить приложение:

1. Откройте решение `WarehouseManagement_Oshchepkov.sln`
2. В Обозревателе решений (Solution Explorer) найдите проект `WarehouseManagement_Oshchepkov.WPF`
3. Нажмите на него правой кнопкой мыши
4. Выберите "Назначить запускаемым проектом" (Set as Startup Project)
5. Нажмите F5 или кнопку "Запустить"

# WarehouseManagement_Oshchepkov

## Описание
WPF приложение для управления складом с партионным учетом товаров.

## Технологии
- C# / WPF / .NET 6.0
- MVVM
- NUnit (Unit-тесты)

## Функционал
- Управление организациями (CRUD)
- Управление складами (привязка к организации)
- Управление товарами (таблица, фото, остатки)
- Импорт товаров из CSV
- Партионный учет (накладные)

## Запуск
1. Открыть `WarehouseManagement_Oshchepkov.sln`
2. Собрать решение (Ctrl+Shift+B)
3. Запустить (F5)
